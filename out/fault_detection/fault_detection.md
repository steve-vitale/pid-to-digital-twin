# Fault detection with the normal bands: all 21 Tennessee Eastman faults

Generated by `scripts/fault_detection_eval.py` from the Braatz data set (`python scripts/fetch_te_data.py --all`). One sample = 3 minutes; each fault switches on at sample 160.

**Rule (fixed before scoring):** the plant is flagged when any of the 52 channels is outside its band (K = 6). A fault counts as detected at the first post-onset sample that starts 3 consecutive flagged samples (9 minutes). Detection rate = share of the 800 post-onset samples flagged.

False-alarm data, all normal operation the method never fitted on:

- Shipped bands: d00.dat (training run): 0/500 flagged samples, 0 alarm events; fault runs, samples 0-159 (21 runs): 0/3360 flagged samples, 0 alarm events
- Refit bands: d00_te.dat (test run, all 960): 0/960 flagged samples, 0 alarm events; fault runs, samples 0-159 (21 runs): 0/3360 flagged samples, 0 alarm events
- PCA T²: d00_te.dat (test run, all 960): 14/960 flagged samples, 1 alarm events; fault runs, samples 0-159 (21 runs): 31/3360 flagged samples, 4 alarm events

Zero false alarms is a measurement on 193 plant hours, not a guarantee: the 95% upper bound is about 0.373 alarm events per day. PCA T² would raise about 0.93 chance alarm events in a 40-hour post-onset window, so a late PCA detection with a detection rate near its 1.0% normal flag rate (faults 3, 4 and 15 below) is probably chance rather than a real detection.
