# Features: what this repository does, and the evidence that each part works

Generated by `scripts/feature_catalog.py` from `data/features.json` and `data/reviews.json`. **Reviewed example** means committed example outputs, tests that pin them, and an independent review whose recorded file hashes still match those outputs. It does not mean the complete route is automated, all input formats connect, or a plant deployment has been accepted. Missing evidence is listed as a gap. Reviews here are independent coding-agent or model checks; each record states its scope and limits. They can include corrective review after findings and are not a person's sign-off.
