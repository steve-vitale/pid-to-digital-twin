# Features: what this repository does, and the evidence that each part works

Generated by `scripts/feature_catalog.py` from `data/features.json` and `data/reviews.json`. **Proven** means committed example outputs, tests that pin them, and an independent review whose recorded file hashes still match those outputs. Anything less is listed as a gap. A reviewer here is a fresh agent or model given only the outputs and their sources, never the conversation that built them; reviews are not a person's sign-off.
