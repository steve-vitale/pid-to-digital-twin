1. Bind a small packet of 6-10 questions and sourced proposals to three original primary files: the 2016 device configuration, the later device configuration, and a real archived Hurco04 operating log. Pin the repository's reuse notice as a fourth ancillary file. Use immutable commit URLs, byte counts, SHA-256 and exact XML/physical-line locators. Keep original files in the ignored external cache.
2. Use the explicit machine UUID `mtc_adapter008` as the packet's asset identity. Preserve `Hurco04` as its source name. A data-item ID is scoped to its document revision; repeated `Hurco04-path_7` must not join tool number to runtime or create a permanent signal alias.
3. Scope different revision observations to separate canonical claim keys. Different documented meanings in different versions must not become an automatic simultaneous contradiction. Keep the configuration deployed during the 2017 recording explicitly unknown.
4. Preserve raw `UNAVAILABLE`, numerical zero, blank program name, recorded status and timestamps as distinct source values. An archived controller reading does not establish production activity, a named job, complete state coverage or present machine condition.
5. No human owner, assigner, reviewer, approval or plant-truth confirmation is inferred. Proposed answers remain AI-authored drafts; missing controlled records remain visible data requests.
6. Verify original XML and raw records independently of generated answer prose: parse the selected machine and data items, inspect exact raw records, confirm actual bytes and test the reused identifier's two meanings. A source verifier must not manufacture its expected facts by reading the proposed answers.
7. With original cache files available, prepare/apply must retain all source bindings and stable machine joins offline. Copy and synthetically revise one actual source file at a time. Only answers dependent on that document may become stale, with old decisions preserved. Changing an unrelated notice must leave the engineering answers current. Reject unregistered signal/asset references and mismatched source hashes.
8. Record the results and any failures without treating this packet as human-reviewed, a timed engineering study or evidence of broad transfer. The independent parent/reviewer check is separate from this coding agent's development checks.
